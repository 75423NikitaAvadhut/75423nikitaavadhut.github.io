Work

Selected projects

Internal database operations platform Enterprise project +

Developers who needed a database change had to raise a request and wait for another team to action it. I built the backend query generation for an internal platform that let them do it themselves through guided templates — altering tables, renaming or adding columns, updating rows, running reports — and wrote several of the templates.

Delete operations were deliberately excluded and every action was logged, so routine work stopped queueing without giving anyone unrestricted access to the database.

  • Spring Boot
  • React
  • MySQL
  • Oracle
  • PostgreSQL
E-commerce test automation Enterprise project +

Testing for a medical equipment e-commerce platform used by a multinational healthcare client. I covered the transactional core: order placement across multiple purchase types including direct purchase and consignment, invoicing, returns and exchanges, order and return history, catalogue browsing and product detail pages.

I tested each flow manually first, then automated it with Robot Framework. Alongside writing new scripts I ran regression cycles, maintained the framework, stabilised existing scripts as the application changed, and prepared SIT documentation.

  • Robot Framework
  • Manual testing
  • Regression
  • SIT documentation
  • JIRA
  • ServiceNow
